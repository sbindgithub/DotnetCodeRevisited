# Azure SQL Database

## What it is
Managed relational database service.

## Models
- DTU (simple)
- vCore (more control, recommended)

## Features
- Automatic backups
- High availability
- Geo-replication

## Scaling
- Vertical scaling (increase compute)
- Elastic pools for multiple DBs

## Performance Issues
- Throttling if limits exceeded
- Connection limits

## When to Use
- Structured relational data
- OLTP systems
