# Azure App Service

## What it is
PaaS service to host web apps and APIs.

## Features
- Auto scaling
- Deployment slots (zero downtime)
- HTTPS, custom domains

## Deployment
- CI/CD via Azure DevOps / GitHub Actions

## Scaling Strategy
- Horizontal scaling (instances)
- Based on CPU, memory, or requests

## Limitations
- Less control than VMs/AKS
- Cold start in some cases

## When to Use
- Web APIs
- Standard business apps
